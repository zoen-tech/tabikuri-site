## 共通の動作

- 既存のルート `prices.js` を相対パスで読み、`PRICES` の24通りだけを使用。価格を新たに定義・保存しない。元ファイルのDOM描画は対象IDを変えることで起動させず、同じ配列を韓国語の料金表示に使う。
- 容量・本数とも初期選択なし。容量を選ぶと4つの本数ボタンに対応する総額が表示される。容量変更時は本数と長期滞在チェックを解除。
- 24/48本は原文の持ち込み上限を表示し、チェックがなければ追加不可。追加すると小窓が開き、下部の帯に保存された件数・本数・処方時料金を表示。
- 追加済みの内容があれば下部の帯は常にその内容を表示。未追加の選択と保存済みの内容を混同しない。
- localStorageには容量・本数・長期滞在確認・有効期限だけを保存。7日で失効。破損データは復旧、読込・書込拒否時は画面内のメモリに切り替える。AとBの保存キーは分離し、それぞれS1/S2で共有。
- `site/config.js`: `BRAND_NAME`、`LINE_ADD_URL=""`、`ALLOW_MULTI_LINES=false`、`NOINDEX=true`。複数行を許可すると容量ごとに1行で保持し、合計12本超に確認を求める。
- S4未実装の段階で外部予約へ進ませない。小窓の予約ボタンは「準備中」で、現行のメール案内を表示。設定値にURLを入れても、このデザイン案から直接予約へ遷移しない。
- 重要事項7項目は両画面と小窓で全文を開閉可能。原文の順序を保持。必須2文は追加ボタン直上に表示。キャンセル・持ち込み・特商法・フッターも原文を保持。
